## 使用方法

### 环境要求

- [Obsidian](https://obsidian.md/) v1.5+
- 已安装插件：Calendar、Dataview、Excalidraw、Templater、Copilot 等

### 开始使用

1. 克隆仓库到本地
2. 在 Obsidian 中「打开文件夹作为仓库」
3. 信任并启用社区插件
4. 从 `diary/` 的今日日记开始你的学习

### 笔记约定

- **Frontmatter**：每篇笔记包含 `tags`、`date`、`status` 等元数据
- **内部链接**：使用 `[[wikilink]]` 互联知识点
- **状态标记**：🌿 进行中 | ✅ 完成 | ⬜ 待创建
